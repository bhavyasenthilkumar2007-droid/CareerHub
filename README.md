
# CareerHub

A full-stack job portal built using HTML, CSS, JavaScript, Node.js, Express, and SQLite.

## Features
- Browse and search jobs
- Filter jobs by category and location
- Save jobs
- Post, edit, and delete jobs
- Apply for jobs
- View application history
- Update application status

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.
